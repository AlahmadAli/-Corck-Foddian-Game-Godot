# Corck

This is an idea my friend and I had for a video game. The plan was to mix roguelite elements with Foddian movement design to create an extremely frustrating yet addicting game.

## The idea:

In this game, you are a crocodile astronaut clumsily making your way up procedurally generated asteroids, picking up powerups along the way. One wrong slam into an asteroid and you
tumble down till you land somewhere. Once you make it to the top, you fight a boss and continue repeat until you die (or ragequit).

In the end my friend an I gave up the project early because we found out that we only really enjoy the programming and game design part of game development, but have no passion for 
the art, animation etc. (Basically anything that requires artistic talent). The idea for the game is free for anyone to make I guess. If you are a game developer and are reading this and think
the idea is cool, please make the game I'd play it.
